# 题型分布方案

## 核心原则

1. **维护总体题目数**：通过重新分配题型，不增加或减少总题数
2. **学科特性导向**：每个学科的题型分布应符合其教学目标
3. **年级渐进**：不同年级的题型分布有差异
4. **删除题目备份**：任何被调整的题目存入 data/backup/ 目录

## 数学学科 (math)

### 当前问题
- choice: 9.4% (3,255题)
- numeric: 90.6% (31,499题)
- short: 0% (0题) ❌ 缺失

### 目标分布 (按年级)
| 年级 | choice比例 | short比例 | numeric比例 | 题型说明 |

| 小学一至四年级 | 15% | 25% | 60% | 基础运算填空题为主 |

| 高中一至三年级 | 30% | 40% | 30% | 综合应用题居多 |

### 操作方案
1. 从 numeric 题目中抽取约 10% 的题目改为 short 类型
2. 从 numeric 题目中抽取约 10% 的题目改为 choice 类型
3. 生成适合每个年级的填空题模板

## 操作步骤

1. **分析现有题目**：统计各学科、年级、题型的当前分布
2. **确定调整幅度**：计算需要转化的题目数量
3. **分类备份**：将被调整的题目移动到 `data/backup/questions_to_adjust.json`
4. **生成新题目**：按目标分布生成缺失题型
5. **更新题目库**：替换题目类型
6. **验证通过**：确保所有题目通过验证

## 年级划分标准

- **小学**：grade 1-6
- **初中**：grade 7-9  
- **高中**：grade ≥10 或 chapter 以 "必修"/"选必" 开头
