# 对抗审核结论报告（2026-11-06）

对 `data/questions.json`（35662 题 / 3504 个正式知识点 / 5233 条先修边）做的一轮**对抗性审核**：不接受既有闸门的绿灯，另找六条独立证据链去证伪。报告里的每个数字都注明**来源与置信档**：

- **实测**＝脚本可复跑，本文所列脚本名即入口；
- **人工逐读**＝逐条读过题干后才定性，不靠抽样；
- **不可证**＝现有工具拿不出字面证据，本轮没有动。

北极星口径贯穿全篇判定标准：**题目是对应知识点的，全库只有一份总题库**——所以「挂在哪个知识点」和「来自哪套教材」是两回事，挂错点＝违反口径，而不是排版问题。

## 三、三处订正（ earlier 结论不成立，以本轮为准）

1. **「题目与知识点对应」从未被体检过**。此前文档只声明「题只挂 `topicId`」，没验证过挂得对不对；本轮实测出 309 道错挂并修复，同时必须承认还有 **863 道**（补充题 7427 道里的 11.6%）n-gram 疑点**不可证**，一道未动。
2. **「147 项 LaTeX 破损」是低估**。全库实际 900+ 处、1200 余个字段；`verify` 里存的字符串引用也一起坏了，所以修完符号还必须按 `json.dumps(正确选项文字)` 重同步 **12623 条**，否则 `mismatch` 会成片报出。
3. **`_s37_mismatch.py` 的前后值不可比**（898/7205 → 863/7427）。转挂必然重编号（`validate.py:1189` 要求 id 前缀＝`topicId`），而该脚本只统计 `_q11` 及以后的补充题，重编号改变了这批题的构成。这两个数只能说明**量级没变**，不能当修复率引用。
4. **「删除 1040 道跨点重复」的说法不准**。`_dup6.txt` 里的 1040 道是**重复规模**（343 组的全部重复题，含每组要保留的那条）；实际删除 **694 道**（`_surgery2.txt`，另有 3 组「组内全是 q1」回退不删——q1 删不得，因为它的题干必须等于该知识点的 `diagnostic_question`）。同理 A 类的 1057 是筛查命中数，删除数是 1058（`_surgery1.txt`）。筛查量与执行量必须分开写。

## 四、这一轮修不了的东西（天花板，诚实口径）

- **无人审**：出题与复核是同一模型家族，共同误解不会被暴露；「mismatch 0」是「没发现分歧」，不是「保证无错」。
- **字母闸门只看得到 0.5% 的选择题**：24654 道 choice 里解析写了字母的仅 112＋24 道，切片内 19/112 有缺陷（≈17%），其余解析是否讲得通不在该闸覆盖范围。
- **`source` 标注缺 39.4%**（14067 道：数学 3647、英语 3360、语文 3179、科学 1440、物理 1077、道法 592、历史 536、地理 236）——分不清教材原练与 AI 补写。本轮**没有回填**，因为回填等于编造证据。
- **CSF `knowledge_point` 只是单元级证据**：816 条 CSF 题匹配 704 道库内题，但它的标签粒度粗于本库知识点（如「分数乘整数的意义与计算」落在四个相邻点之间），所以只有**标签名＝知识点名**（score ≥ 0.9）的 2 道被采信，其余 503 条「mismatch」是标签粒度差，不是错挂。
- **302 个初中语文知识点没有 challenge 档**（另英语 1、道法 2），每点固定 4 题的池子天然缺拓展档；这是建池时的取舍，不是本轮遗漏。
- 证明题、作图题、真正需要图的题仍以文字描述；`self` 题只有 7 道，开放题基本没有。
