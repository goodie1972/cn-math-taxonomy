### 年级 ↔ 池子册次

- 六三制省份：该省 N 年级 = 池子里的人教 N 年级册次（一上~九下），无偏移。
- 五四制省份（上海、山东烟台/威海/东营、黑龙江哈尔滨城区等）：**六年级属初中（预备班）**，该省六年级 = 池子里的人教七年级（七上/七下），七年级=八上/八下，八年级=九上/九下，八年级期末即学完初中内容，九年级多出一年用于复习与高中先修。
- 因此同一套知识点池，五四制省的年级标签要整体下移一个学年；这一偏移属于「版本 = 归属层」，不需要重建知识点。
