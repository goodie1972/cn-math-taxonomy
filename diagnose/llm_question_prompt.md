# 多角度出题 Prompt 模板（LLM 生成诊断题）

用途：围绕**单个知识点 `topicId`**，由 LLM 生成**结构多样**的练习题，写入 `data/questions.json`，供诊断引擎抽取。
核心目标不是"同一骨架换数字"，而是**真正的多样性**——不同题型、不同真实情境、不同设问方式、不同难度梯度。

> 背景：当前题库每个知识点只有 4~5 道固定题，"变换不重复"上限很低。靠"自己造题/换数字"治标不治本；
> 真正的多样性来自两种合法路径：
> （1）真实题源对齐（教材 PDF / 国家智慧教育平台 OCR 后由 LLM 打 `topicId` 标签）；
> （2）本模板——LLM 围绕一个 `topicId` 从多角度生成结构多样的题。
> 两路共用"对齐到 `topicId`"这件关键资产。

---

## 一、输入（调用时必须提供）

- `topicId` 与知识点名称（例：`cnm_010` 有理数的加法法则）
- 该点对应的教材要求 / 课标描述（约束出题边界，防止超纲）
- 期望题量（建议 **≥10**，才能支撑"同点 10 次不重复变换"）
- 目标学段（例：七上，避免出到高中内容）

## 二、硬规则（违反任一条引擎都不会正常出该题）

1. 每道题**必须**带 `topicId`，否则引擎不会出它。
2. 字段严格遵循 `data/questions.json` 现有格式，**不要新增未知字段**：
   - 数值计算 `type:"numeric"`：
     `{ "difficulty", "type":"numeric", "prompt", "answer", "explanation", "verify", "id", "topicId" }`
     `verify` 必须是**求值后等于 `answer`** 的表达式（如 `answer:"5"` 则 `verify:"-4+9"`）。
   - 选择 `type:"choice"`：
     `choices:[{"key":"A","text":"..."}, ...]`，`answer` 为选项 key（如 `"C"`），`verify` 为值字符串如 `"'C'"`。
   - 简答 `type:"short"`：可加 `accept:[...]` 列可接受的等价答案；无需 `verify`。
   - 自评 `type:"self"`：开放式，给 `answer` 作参考答案；无需 `verify`。
3. `difficulty` ∈ `basic(0) | standard(1) | challenge(2) | advanced(2)`，**三档都要覆盖**，引擎才会在"初测→连续答对确认→答错补基础"各阶段都有题可抽。
4. `id` **全局唯一**，格式 `{topicId}_q{N}`，N 不能与现有题冲突（先查该点现有最大编号）。

## 三、多样性维度（每条题都要换角度，严禁"只换数字"）

- **题型轮换**：数值计算 / 单项选择 / 简答 / 判断说理 / 纠错找错
- **情境轮换**：纯运算、温度、海拔、收支记账、行程、比赛比分、化学离子、几何图形……尽量贴近真实生活
- **设问轮换**：直接计算、逆向求值、给结果反推、纠错、真假判断并举例、说理、列方程式解应用题
- **难度梯度**：`basic` 巩固法则 → `standard` 标准应用/含情境 → `challenge` 拓展/多步/说理

## 四、输出格式

直接输出一个 JSON 数组，元素符合上述字段；每道题另附一行中文，说明它的**多样性角度**（题型+情境+设问），便于人工抽检与去重。

## 五、质量兜底（生成后必须做）

- 逐题核对 `verify` 求值 == `answer`；
- 抽查答案与解析是否自洽、是否超纲；
- 仓库声明本就是"AI 初稿待教师核对"，生成题需标注来源为 LLM 生成，进入人工审核流。

---

## 附：调用示例（给 LLM 的 prompt 骨架）

```
你是初中数学出题专家。请围绕知识点 {topicId}（{名称}），依据"{课标描述}"，
为{七上}学生生成 {10} 道结构多样的练习题，写入 data/questions.json 格式。

要求：
- 覆盖 basic/standard/challenge 三档难度；
- 题型在 数值/选择/简答/说理 间轮换；
- 情境尽量真实多样（温度、海拔、收支、行程、比赛等），不要只换数字；
- 每个 id 用 {topicId}_q{N}（N 从现有最大编号+1 起，全局唯一）；
- numeric 题的 verify 必须求值等于 answer；choice 题 answer 为选项 key、verify 为 "'值'"；
- 输出 JSON 数组，每题后附一行"角度：题型+情境+设问"。
```
